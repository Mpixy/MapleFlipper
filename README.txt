MapleFlipper - מוצא אייטמים בחנויות שחקנים שמשתלם למכור ל-NPC

הפעלה:
 1. קליק ימני על MapleFlipper-Windows.zip -> Extract All
 2. לחיצה כפולה על MapleFlipper.exe
 (לא צריך Python ולא שום התקנה. אם Windows מציג "Windows protected your PC" -> More info -> Run anyway)

שימוש:
 - נכנסים לחנות של שחקן - עם Auto דלוק התוכנה מזהה וקוראת לבד (או F8).
 - הפס הגדול אומר מה לקנות: ירוק = עסקה, זהב מהבהב = עסקה ענקית, אפור = אין כלום, לחנות הבאה.
 - צהוב "price?" = המחיר לא נקרא בוודאות - תבדוק בעין לפני שקונים.
 - כתום (?) = אין מחיר לאייטם. שורות אפורות בחנות (נמכרו) וחצים - מדולגים.

מקשים:
 F8 סריקה · F9 פס קטן מעל המשחק / חלון מלא · F10 ניקוי הרשימה

עוד:
 - 👀 Watch: רשימת אייטמים שתמיד תקבל עליהם התראה (מסגרת סגולה + צליל).
 - Shops: חנויות שכבר בדקת ומה היה בהן. Stats: רווח היום / שבוע / תמיד.
 - 💎 NX: כשעוברים עם העכבר על אייטם ורואים את המטבע האדום C - התוכנה לומדת לבד שזה NX (לא נמכר ל-NPC).
   אייטם שנמכר ל-NPC נלמד לבד כאייטם רגיל. אפשר גם לתקן בקליק ימני.
 - 🔵 כחול = זול: התוכנה זוכרת את 20 המחירים האחרונים של כל אייטם מהחנויות שאתה פותח.
   מחיר מתחת ל-80% מהנמוך שבהם (אחרי שיש לפחות 5) = שורה כחולה + טיק שקט.
 - 🔊 סרגל ווליום ליד Beep. קליק ימני על אייטם במעקב -> Stop watching.
 - ✔ קנייה מזוהה לפי ירידת המזו + השורה שנעלמה מהחנות. אם פספס: קליק ימני -> I already bought this.
 - 🖱 מעבר עם העכבר על כל אייטם בחנות: התוכנה קוראת את השם המדויק מחלון המידע ומתקנת לבד שמות שקראה לא נכון.
 - ⟳ Restart אם התוכנה נתקעת - שום דבר לא הולך לאיבוד.

טרקר מזו:
 - פותחים אינבנטורי -> Set mesos area -> גוררים ריבוע סביב מספר המזו -> Start tracking.
 - קנייה = שורה כחולה BOUGHT. מכירה ל-NPC מזוהה לבד (גם כמה אייטמים ביחד).
 - לחיצה על "Sell to NPC" = לסמן מה כבר מכרת.

How to use (English):
 Extract the zip, run MapleFlipper.exe. Open a player shop and press F8.
 Green rows can be bought and sold to an NPC for profit. Click "? Help" in the app for more.
